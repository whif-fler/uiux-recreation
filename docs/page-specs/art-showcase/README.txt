PALLET ROSS UI RECREATION
===========================

Files
- index.html: standalone semantic page
- styles.css: all page and responsive styling
- visual-spec.md: measured visual reconstruction notes
- assets/: seven original SVG art assets

Run
Open index.html directly in a browser, or serve this folder with any static server, for example:

  python3 -m http.server 8000

Then visit http://localhost:8000.

Reference viewport
Render at 1282 x 754 pixels for the closest match to the supplied screenshot.

Implementation notes
No frameworks, external fonts, remote assets, JavaScript, canvas, screenshot slicing, or embedded reference image are used.
