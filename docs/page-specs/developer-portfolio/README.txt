STAGE UI RECREATION

Files:
- index.html
- styles.css
- visual-spec.md
- assets/avatar.svg

Run locally:
1. Open index.html directly in a browser, or
2. From this directory run: python3 -m http.server 8000
3. Visit: http://localhost:8000

Reference viewport:
- 1200 x 666 CSS pixels

Implementation notes:
- Plain semantic HTML and CSS only.
- No React, Tailwind, Bootstrap, component framework, or JavaScript.
- The screenshot is not embedded or used as a background.
- Interface icons are inline SVG.
- The visible profile image is a custom local SVG approximation.
- Third-party logo-like marks are typographic approximations rather than copied brand assets.
